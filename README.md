# McCoy's Store Pickup Reallocation — 2027 Proposal

`index.html` — redeploy 13 underutilized store pickups (worst combined miles + all-in cost-per-mile rank, Jan–Oct 2026) to the 2027 lifecycle replacements (including three at Millworks) and the Region 1, 4 and 6 pickups.

- **Store P&L savings:** flat pickup billing of $995.46/month per store removed — $155,292/year.
- **CAPEX avoided:** 13 new pickups × $55,000 delivered — $715,000.
- **Placement:** by mileage — lowest-odometer trucks go to the highest-usage receiving stores.

Open `index.html` in a browser, or enable GitHub Pages (Settings → Pages → Deploy from branch `main`, `/root`).

`scripts/` builds the page from the YTD 2026 fleet cost-per-mile dataset (see the Fleet-CMP-HOUR-Analysis repo). Source data files are not stored here.
